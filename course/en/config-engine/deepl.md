# Configure the DeepL Translation Engine

## Step 1: Register a DeepL account
Website: [https://www.deepl.com/](https://www.deepl.com/)

## Step 2: Register a developer account

![](../../assets/config-engine/deepl/1.png)

## Step 3: Subscribe to DeepL API Free
![](../../assets/config-engine/deepl/2.png)
> Note: a VISA credit card is required for verification. If you don't have one, search online for a "virtual overseas VISA credit card" (credit cards issued in mainland China may not work).

## Step 4: Create an API key
![](../../assets/config-engine/deepl/3.png)

Copy the key into Translate-Pro settings → `Translate-next.deepl.key`

That's all — the DeepL engine is ready to use.
