# DeepL 翻訳エンジンの設定

## ステップ 1：DeepL アカウントを登録
公式サイト：[https://www.deepl.com/](https://www.deepl.com/)

## ステップ 2：開発者アカウントを登録

![](../../assets/config-engine/deepl/1.png)

## ステップ 3：DeepL API Free を申し込む
![](../../assets/config-engine/deepl/2.png)
> ヒント：VISA クレジットカードが必要です。お持ちでない場合は、ネットで「海外バーチャル VISA クレジットカード」を検索して購入してください（中国本土発行のカードは使用できない場合があります）。

## ステップ 4：API キーを作成
![](../../assets/config-engine/deepl/3.png)

キーを Translate-Pro 設定 → `Translate-next.deepl.key` にコピーします。

以上で設定は完了です。すぐに利用できます。
