# Azure 機械翻訳エンジンの設定

## ステップ 1：Microsoft アカウントを登録
公式サイト：[https://signup.live.com/signup](https://signup.live.com/signup)

## ステップ 2：Microsoft Azure にサインイン
Microsoft Azure の URL：[https://portal.azure.com/](https://portal.azure.com/)

## ステップ 4：「キーとエンドポイント」を開く
キーと場所（リージョン）を Translate-Pro 設定画面の Azure 項目へコピーします：
`Translate-next.azure.key` と `Translate-next.azure.region`。
![](../../assets/config-engine/azure/5.png)
![](../../assets/config-engine/azure/6.png)

以上で設定は完了です。すぐに利用できます。
